# Collaboration Opportunities

This tool is open-source (AGPL-3.0) and designed to help the HuggingFace ecosystem. We welcome collaboration from:

## 🤝 Organizations & Companies

### Integration Opportunities
- **HuggingFace Datasets Library**: Core merging capabilities
- **Dataset Hosting Platforms**: Bulk processing features
- **ML Training Platforms**: Pre-processing pipeline integration
- **Research Institutions**: Custom dataset curation workflows

### What We Offer
- Production-tested codebase (800K+ examples processed)
- Memory-optimized processing
- Flexible configuration system
- Comprehensive documentation

## 🌍 Community Contributors

We welcome contributions in:
- Bug fixes and performance improvements
- New features (see [Roadmap](#roadmap))
- Documentation and tutorials
- Testing and validation
- Use case examples

See [CONTRIBUTING.md](CONTRIBUTING.md) for guidelines.

- Complements new dataset editing and duplication features
- Standardizes diverse dataset formats
- Enables large-scale dataset curation
- Reduces friction in dataset preparation

### For ML Practitioners
- Saves time on dataset preprocessing
- Ensures format consistency
- Provides quality validation
- Automates repetitive tasks

### For Researchers
- Enables reproducible dataset combinations
- Provides detailed statistics and metadata
- Supports experimental workflows
- Facilitates dataset versioning
